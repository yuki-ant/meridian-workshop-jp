Meridian Components ワークショップ — 生成レポート一式
=====================================================

【注意】要件番号の変更について
RFP（docs/rfp/MC-2026-0417.md）に「R1 概要ページ（ダッシュボード）の改修」を最優先の必須項目として追加し、
以降の番号を1つずつ繰り下げました（旧 R1 Reports → R2、旧 R2 発注推奨 → R3、旧 R3 テスト → R4、旧 R4 アーキテクチャ → R5）。
このフォルダの資料（07-R1-defect-matrix.md、各 HTML など）は旧番号のままです。旧 R1 は現在の R2（Reports）を指します。

すべて単一 HTML です。ブラウザで開くだけで閲覧できます。
（日本語フォントは Google Fonts から取得するため、初回はネットワーク接続が
　あると綺麗に表示されます。オフラインでも内容は読めます）
